Sobre o projeto

Uma plataforma simples para aprender tecnologia

O InfoTech foi desenvolvido para apresentar informações sobre as áreas da informática de forma simples, clara e organizada.

O projeto foi criado como uma aplicação prática de conhecimentos relacionados com HTML5, CSS3, JavaScript, acessibilidade, usabilidade e organização de conteúdos para a web.

Visão e objetivos do projeto

Visão

Mostrar como a informática está presente no dia a dia e apresentar os principais ramos de atuação desta área.

Objetivos

Promover a aprendizagem através de conteúdos curtos, exemplos práticos e uma navegação intuitiva para diferentes utilizadores.

Público-alvo

Estudantes, iniciantes e qualquer pessoa interessada em conhecer melhor as áreas fundamentais da informática.

Tecnologias utilizadas

HTML5

Utilizado para estruturar as páginas, os textos, os links, as tabelas, os formulários e os conteúdos multimédia.

CSS3

Utilizado para definir as cores, o layout, os cartões, a responsividade e os temas claro e escuro.

JavaScript

Utilizado para implementar o menu responsivo, o tema e a interatividade dos cartões e do carrossel.

Acessibilidade e usabilidade

Durante o desenvolvimento foram consideradas práticas para tornar o site mais simples de utilizar e mais acessível para diferentes utilizadores.

  • Menu de navegação consistente em todas as páginas.
  • Layout responsivo para computadores, tablets e telemóveis.
  • Textos alternativos para as imagens.
  • Contraste adequado entre o texto e o fundo.
  • Botões com indicação do seu estado.
  • Possibilidade de navegação através do teclado.
  • Conteúdos multimédia com mensagens alternativas.

Melhorias futuras

Numa versão futura, o projeto poderá incluir uma base de dados, autenticação de utilizadores, sistema de upload de documentos, formulário de contacto ligado a um servidor e uma área administrativa.

Também poderá ser acrescentado mais conteúdo educativo, novos vídeos, exercícios práticos e materiais para download.
